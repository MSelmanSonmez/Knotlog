# knotlog synonyms/tr-en.txt -- Turkish <-> English word equivalents for search.
#
# Read at search time by lib/search.awk (see "Synonyms" in docs/REFERENCE.md).
# Index files are untouched. Active when the vault config says synonyms=tr-en,
# or has no synonyms= line and lang=tr; synonyms=off turns it off.
#
# Every word is written FOLDED: ASCII, lower case, exactly what
# fold/tr.sed + tr 'A-Z' 'a-z' produce (c for c-cedilla, g for g-breve,
# i for dotless i, o, s, u for the umlaut/cedilla letters). The search folds
# and stems the query the same way, so "kurulumu" finds the "kurulum" line.
#
# Two kinds of line (anything else is ignored):
#
#   group line   words separated by spaces. All words mean the same thing: a
#                query word that equals one of them (after stemming) also
#                searches for all the others. Groups never chain: a word that
#                is only in the expansion does not expand again.
#                    kurulum setup install
#
#   join line    "words = compound": the words written apart mean what the one
#                compound word means. Two consecutive query words that match
#                the left side add the compound; the compound alone adds each
#                of the left words as its own term.
#                    open source = opensource
#
# Lines starting with # and empty lines are comments.
#
# Rules for adding a line: both sides must be genuinely interchangeable in
# ordinary software and everyday text. Words with several meanings are left
# out on purpose, because a wrong synonym buries the right notes:
#   kayit (record / log / registration), gunluk (daily / journal / log),
#   yukleme (upload / install / loading), dal (branch / twig), not (note, and
#   the English word "not"), arac (tool / vehicle), dizin (index / directory).
# Words whose stem is very short are mostly left out too (karar, yorum, sorun,
# bakim, cozum, tema ...): the stem would also match unrelated words, and
# English "theme" would stem to the common word "the". The few that stay
# (dosya, surum, arama, ekran) are core software words and worth it.
# Words must not be vault specific: no note names, project names or tool names.
